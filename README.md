## О проекте

Консольная программа на C# для учёта книг в библиотеке.
Два класса: `Book` (одна книга) и `Library` (фонд книг).

## Класс Book

Что хранит книга:

- `Title` — название (без лишних пробелов, пустое → «Без названия»)
- `Author` — автор
- `Year` — год издания (1450–2100)
- `Pages` — число страниц (не меньше 1)
- `TimesRead` — сколько раз прочитана
- `IsAvailable` — доступна ли сейчас

Что умеет книга:

- `Borrow()` — выдать. Если уже выдана — отказ.
- `Return()` — вернуть. Если уже доступна — отказ. Иначе
  ставит `IsAvailable = true` и увеличивает `TimesRead`.
- `IsLong()` — `true`, если страниц больше 500.
- `GetInfo()` — вернуть строку с данными книги.

Все свойства имеют `private set`: снаружи менять нельзя, только
через конструктор и методы. Это защищает состояние книги.

## Класс Library

Что хранит библиотека:

- `Name` — название (без пробелов, пустое → «Библиотека»)
- `Books` — список книг `List<Book>`

Что умеет библиотека:

- `AddBook(book)` — добавить книгу (если `null` — отказ).
- `PrintAll()` — вывести все книги через `foreach`.
- `CountAvailable()` — посчитать доступные книги циклом.
